# QueueFlow — মাস্টার প্ল্যান (Signature Salon PDF + প্রজেক্ট স্পেক মিলিয়ে)

> উৎস: ৫০-পেজ "Signature Salon" UI ডিজাইন PDF-এর ফিচার এনালাইসিস (`docs/barber-shop-feature-analysis.md`),
> প্রজেক্ট বর্ণনা (Smart Salon Queue & Management System), `PROJECT-SPEC.md`, README রোডম্যাপ, এবং কোডবেসের বর্তমান অবস্থা।
>
> **মূল পার্থক্যটা মাথায় রাখা জরুরি:** Signature Salon একটা *appointment/slot-booking* অ্যাপ (দিন+টাইম স্লট বেছে বুকিং),
> আর QueueFlow একটা *লাইভ কিউ/সিরিয়াল* প্রোডাক্ট (এখনই লাইনে দাঁড়ানো, লাইভ ETA)। তাই PDF থেকে আমরা নেব
> **UI/UX প্যাটার্ন, কালার-স্টাইল আর সাপোর্টিং ফিচার** — কিন্তু কোর বুকিং মডেল থাকবে QueueFlow-র কিউ ইঞ্জিনই।

## ২. ডিজাইন সিদ্ধান্ত — Signature Salon স্টাইল অ্যাডপশন 🎨

তোমার সিদ্ধান্ত: **PDF-এর কালার + UI/UX ফলো করা হবে, ভাষা বাংলা (পরে ইংরেজি টগল)।**

বর্তমান অ্যাপ Palaa (Warm) থিমে স্টাইল করা। PDF ফলো করতে হলে একটা **টোকেন-লেভেল রি-স্কিন** লাগবে — যেহেতু Sprint 0-তে সব রং CSS ভ্যারিয়েবলে (`--accent`, `--paper`, `--card`...) আছে, এটা তুলনামূলক সস্তা কাজ:

- **Accent:** লাল/কোরাল (#E85B5B ঘরানার, PDF থেকে exact স্যাম্পল নেওয়া হবে) — বাটন, active ট্যাব, ব্যাজ, লিংক
- **সারফেস:** সাদা/অফ-হোয়াইট কার্ড, হালকা ধূসর ব্যাকগ্রাউন্ড, নরম শ্যাডো, বড় রেডিয়াস (ফুল-পিল বাটন)
- **প্যাটার্ন:** iOS-স্টাইল বটম নেভ (৫ ট্যাব), স্টিকি বটম CTA, বটম-শিট (বুকিং/লগআউট কনফার্ম/শেয়ার), চিপ-ভিত্তিক পিকার (day/time/ফিল্টার), হরাইজন্টাল স্ক্রল ট্যাব বার, হিরো-ইমেজ হেডার + ফ্লোটিং রেটিং ব্যাজ
- **টাইপোগ্রাফি:** বাংলা-প্রথম (Hind Siliguri/Anek Bangla রাখা যায়), পরিষ্কার হায়ারার্কি
- Warm/Cool টগলের বদলে এখন সিদ্ধান্ত: **Signature-রেড থিমই ডিফল্ট**; আগের Sprint 10-এর "থিম টগল" স্কোপ থেকে বাদ (চাইলে পরে light/dark হিসেবে ফিরবে)

## ৩. PDF-এর ৫০ স্ক্রিন থেকে ফিচার বাছাই

### ৩.১ নেব — সরাসরি (QueueFlow-তে নেই, দরকারি)

| # | PDF ফিচার | QueueFlow-তে রূপ |
|---|---|---|
| N1 | **Notification Center** (ডেট-গ্রুপড লিস্ট + বেল আইকন) | কিউ ইভেন্ট ("সিরিয়াল কনফার্ম", "আর ২ জন বাকি", "এখন তোমার পালা"), রিটেনশন রিমাইন্ডার, দোকানদারের পাঠানো প্রমো — সবগুলোর in-app লিস্ট + Web Push |
| N2 | **Favorites/Saved** (♥ টগল + ক্যাটাগরি ফিল্টারসহ Saved পেজ) | প্রিয় দোকান সেভ, explore-এ ♥, প্রোফাইলে "প্রিয় দোকান" লিস্ট |
| N3 | **Bookings হিস্ট্রি ৩-ট্যাব** (Upcoming/Completed/Cancelled) + **Re-Book** + **Remind me টগল** | বিদ্যমান serial হিস্ট্রিকে এই লেআউটে আনা; Re-Book = same shop+services এক ট্যাপে নতুন সিরিয়াল |
| N4 | **E-Receipt** (বারকোড/QR + আইটেমাইজড বিল + ডাউনলোড) | সিরিয়াল কমপ্লিট হলে ডিজিটাল রসিদ; QR-এ serial code — দোকানে দেখানো যাবে |
| N5 | **Salon Detail ট্যাব স্ট্রাকচার**: সার্ভিস / স্টাফ / **গ্যালারি** / **রিভিউ** / **About + Working Hours টেবিল** | শপ ডিটেইল পেজকে ট্যাবড লেআউটে আপগ্রেড; গ্যালারি (দোকানদার ছবি আপলোড), সাপ্তাহিক সময়সূচি টেবিল |
| N6 | **Quick Actions রো**: Call · Message · Direction · Share | Call=tel: লিংক, Message=বিদ্যমান চ্যাট, Direction=ম্যাপ লিংক/রুট, Share=share API |
| N7 | **Filter স্ক্রিন**: ক্যাটাগরি চিপ, রেটিং রেঞ্জ, দূরত্ব স্লাইডার, Male/Female (=Salon/Parlour!) | Explore-এ ফিল্টার বটম-শিট — business_type ম্যাপ হয় Male/Female-এ |
| N8 | **Forgot Password + OTP ফ্লো** | Supabase auth দিয়ে পাসওয়ার্ড রিসেট (ইমেইল OTP/লিংক) |
| N9 | **Profile মেনু** পূর্ণাঙ্গ: Payment Methods, Saved, Settings (Password Manager, Delete Account, Notification Settings), Transactions, Help Center (FAQ+Contact), Privacy Policy, Logout কনফার্ম শিট | কাস্টমার ও প্রোভাইডার দুই সাইডেই সেটিংস হাব |
| N10 | **Transactions হিস্ট্রি** (ডেট-গ্রুপড, amount) | কাস্টমার সাইড পেমেন্ট হিস্ট্রি (দোকানদারের ইনকাম ভিউ তো আছেই) |
| N11 | **Chat আপগ্রেড**: Chats লিস্ট (সব কনভার্সেশন), online স্ট্যাটাস, ছবি পাঠানো | বিদ্যমান বুকিং-স্কোপড চ্যাটের উপরে |
| N12 | **Location অনবোর্ডিং**: GPS permission স্ক্রিন + ম্যানুয়াল লোকেশন সার্চ | কাস্টমারের কাছের দোকান সাজানোর জন্য (দূরত্ব-সর্ট এখনো নেই — একসাথে হবে) |
| N13 | **Home স্ক্রিন সেকশন**: প্রমো ব্যানার ক্যারোসেল + ক্যাটাগরি আইকন + টপ-রেটেড | Explore-কে "হোম"-এ রূপ: উপরে দোকানদারদের চলমান **অফার ব্যানার**, সার্ভিস-ক্যাটাগরি শর্টকাট, টপ-রেটেড সেকশন |

### ৩.২ নেব — অ্যাডাপ্ট করে (QueueFlow-র মডেলে মানিয়ে)

| # | PDF ফিচার | অ্যাডাপ্টেশন |
|---|---|---|
| A1 | Day+Time স্লট পিকার | **সরাসরি নেব না** — QueueFlow লাইভ কিউ; তবে UI প্যাটার্নটা (চিপ পিকার) walk-in টাইম/"পরে আসবো" প্রি-বুকিংয়ে ভবিষ্যতে কাজে লাগবে |
| A2 | Specialist বেছে বুকিং | চেয়ার/স্টাফ = specialist; বুকিংয়ে **পছন্দের স্টাফ (optional)** বাছার অপশন — auto-assign-এর পাশে |
| A3 | Specialist প্রোফাইল + per-staff রেটিং | চেয়ার/স্টাফ কার্ডে রেটিং দেখানো (রিভিউয়ে স্টাফ ট্যাগ) — পরের ধাপ |
| A4 | রিভিউ ফিল্টার/সার্চ/ছবি | রিভিউয়ে **ছবি অ্যাটাচ** + Latest/With-Photos ফিল্টার; verified = আসলেই সার্ভিস নেওয়া কাস্টমার (আমাদের ডেটায় এটা এমনিই আছে!) |
| A5 | Payment Method স্ক্রিন (Cash/Card/PayPal/ApplePay) | বাংলাদেশ কনটেক্সট: **Cash / bKash / Nagad / Rocket / Card** — অ্যাগ্রিগেটর (SSLCommerz বা aamarPay) দিয়ে; বিদ্যমান mock-gateway ইন্টারফেস সোয়াপযোগ্যভাবেই বানানো আছে |
| A6 | Wait-time নোটিফিকেশন ("~25 min") | এটা তো QueueFlow-র কোর — পুশ নোটিফিকেশনে ETA আপডেট পাঠানো |

### ৩.৪ QueueFlow-এক্সক্লুসিভ (PDF-এ নেই, তোমার স্পেকে আছে — অক্ষত থাকবে)

লাইভ কিউ ইঞ্জিন + ETA রিক্যালকুলেশন, চেয়ার-ভিত্তিক প্যারালাল কিউ, walk-in, one-active-serial এনফোর্সমেন্ট,
Trust Score + Reliability লেবেল, দোকানদারের পূর্ণ ড্যাশবোর্ড (ইনকাম/অ্যানালিটিক্স/regulars) — PDF-এ দোকানদার-সাইড
বলে কিছুই নেই, এটাই তোমার প্রতিযোগিতামূলক সুবিধা।

### ৩.৫ তোমার বর্ণনায় নতুন — কোনো ডকুমেন্টে এখনো নেই ⭐

## ৪. টোটাল ফেজ প্ল্যান 🗺️

> প্রতিটা ফেজ আলাদাভাবে শিপযোগ্য; অর্ডার প্রস্তাবিত — তুমি রিভিউ করে বদলাতে পারো।
> সব ফেজে মোবাইল-ফার্স্ট রেসপনসিভ + বাংলা ভাষা বাধ্যতামূলক।

### Phase 1 — Signature-স্টাইল রি-স্কিন (ভিত্তি)
- ডিজাইন টোকেন সোয়াপ: লাল/কোরাল accent, সাদা কার্ড, পিল বাটন, নতুন শ্যাডো/রেডিয়াস স্কেল
- বটম নেভ ৫-ট্যাব রি-লেআউট (কাস্টমার): হোম · এক্সপ্লোর(ম্যাপ) · আমার সিরিয়াল · চ্যাট · প্রোফাইল
- কমন প্যাটার্ন কম্পোনেন্ট: বটম-শিট, চিপ, ট্যাব বার, হিরো হেডার — সব স্ক্রিনে ধাপে ধাপে প্রয়োগ

### Phase 2 — Auth + অনবোর্ডিং সম্পূর্ণকরণ
- Forgot password (ইমেইল OTP/লিংক), পাসওয়ার্ড চেঞ্জ (Password Manager স্ক্রিন)
- সাইনআপের পর Complete Profile ধাপ (ছবি, ফোন, জেন্ডার)
- Location permission স্ক্রিন + ম্যানুয়াল লোকেশন সার্চ; **দূরত্ব-ভিত্তিক সর্টিং** explore-এ

### Phase 3 — শপ ডিটেইল ২.০ (PDF-এর সবচেয়ে বড় UI আপগ্রেড)
- ট্যাবড লেআউট: সার্ভিস / স্টাফ / গ্যালারি / রিভিউ / বিস্তারিত (About + Working Hours টেবিল)
- হিরো কভার + ফ্লোটিং রেটিং ব্যাজ + Quick Actions (কল, মেসেজ, ডিরেকশন, শেয়ার)
- দোকানদার সেটিংসে: গ্যালারি আপলোড, সাপ্তাহিক সময়সূচি, About টেক্সট
- বুকিংয়ে পছন্দের স্টাফ (optional) সিলেক্ট

### Phase 4 — নোটিফিকেশন সিস্টেম (কোর ভ্যালু!)
- `notifications` টেবিল + in-app Notification Center (বেল + ব্যাজ + ডেট-গ্রুপড লিস্ট)
- Web Push (service worker): সিরিয়াল কনফার্ম / "আর N জন" / "এখন তোমার পালা" / ক্যানসেল
- দোকানদার → কাস্টমার প্রমো ব্রডকাস্ট + রিটেনশন রিমাইন্ডার অটো-পাঠানো
- Notification Settings (কোন ধরনের নোটিফিকেশন চাই)

### Phase 5 — হিস্ট্রি, রসিদ ও Favorites
- Bookings ৩-ট্যাব (চলমান/সম্পন্ন/বাতিল) + Re-Book + Remind-me টগল
- E-Receipt: QR/বারকোডসহ রসিদ পেজ + ডাউনলোড; Transactions লিস্ট (কাস্টমার)
- Favorites: ♥ টগল + Saved পেজ (ক্যাটাগরি ফিল্টার)

### Phase 6 — হোম রিচনেস + ফিল্টার + অফার
- হোম সেকশন: অফার ব্যানার ক্যারোসেল, ক্যাটাগরি শর্টকাট, টপ-রেটেড দোকান
- দোকানদারের অফার তৈরির টুল (টাইটেল, ডিসকাউন্ট, মেয়াদ) → ব্যানারে + নোটিফিকেশনে
- Explore ফিল্টার বটম-শিট: ক্যাটাগরি, রেটিং রেঞ্জ, দূরত্ব স্লাইডার, Salon/Parlour
- সার্চ (দোকান/সার্ভিস নামে)

### Phase 7 — পেমেন্ট (রিয়েল) + বাকি খাতা
- SSLCommerz/aamarPay স্যান্ডবক্স ইন্টিগ্রেশন (bKash/Nagad/Rocket/Card এক গেটওয়েতে) — বিদ্যমান mock ইন্টারফেস সোয়াপ
- Payment Methods স্ক্রিন; Advance / Pay-after-service ফ্লো ফাইনাল
- **বাকি খাতা**: DUE স্ট্যাটাস, দোকানদারের বাকি ট্র্যাকিং পেজ, আদায় মার্ক, কাস্টমার-প্রতি ব্যালেন্স

### Phase 8 — চ্যাট ২.০ + রিভিউ ২.০
- Chats লিস্ট (সব কনভার্সেশন একসাথে), online/unread ইন্ডিকেটর, ছবি মেসেজ
- রিভিউয়ে ছবি অ্যাটাচ, ফিল্টার (Latest/With Photos), verified ব্যাজ; স্টাফ-প্রতি রেটিং

### Phase 9 — সাপোর্ট পেজ + পলিশ (পুরনো Sprint 10)
- Help Center (FAQ অ্যাকর্ডিয়ন + Contact), Privacy Policy/T&C, Delete Account ফ্লো, Logout কনফার্ম শিট
- ফুল রেসপনসিভ QA পাস, অ্যানিমেশন পলিশ, এম্পটি/এরর স্টেট

### Phase 10 — ভাষা টগল (পুরনো Sprint 11)
- স্ট্রিং ডিকশনারি রিফ্যাক্টর → বাংলা ডিফল্ট + ইংরেজি টগল, প্রেফারেন্স persist

### Phase 11 — টেস্টিং ও হার্ডেনিং (পুরনো Sprint 12)
- ETA ইউনিট টেস্ট, বুকিং→ট্র্যাকিং→Done→ইনকাম E2E, one-active-serial ও payment এজ-কেস

### পরে (ব্যাকলগ)
- Google social login · প্যাকেজ/বান্ডেল · সোশ্যাল লেয়ার (ফলোয়ার) · মাল্টি-ব্রাঞ্চ · SMS নোটিফিকেশন
- অ্যাপে রূপান্তর (PWA আগে — installable + push তো Phase 4-এই আসছে; পরে চাইলে React Native/Capacitor)
- অন্য ভার্টিক্যাল (ডাক্তার চেম্বার, কার ওয়াশ...) — business_type আর্কিটেকচার এমনিতেই প্রস্তুত

## ৫. সিদ্ধান্ত (কনফার্মড ✅)

1. **রি-স্কিনের গভীরতা:** Palaa-র লেআউট স্ট্রাকচার রিইউজ, শুধু কালার টোকেন + কম্পোনেন্ট স্টাইল Signature-রেডে সোয়াপ।
2. **ফেজ অর্ডার:** নোটিফিকেশন এগিয়ে Sprint 2-এ; রিয়েল পেমেন্ট গেটওয়ে **এখন ইন্টিগ্রেট হবে না** — Payment Methods UI/অপশন রেখে দেওয়া হবে (mock ইন্টারফেস অক্ষত), গেটওয়ে পরে সোয়াপ।
3. **পেমেন্ট অ্যাগ্রিগেটর:** পরে সিদ্ধান্ত (ব্যাকলগ)।
4. **প্রোভাইডার UI:** ডার্ক সাইডবার লেআউট থাকবে, শুধু accent Signature-রেডে।
