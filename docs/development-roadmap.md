# QueueFlow — ডেভেলপমেন্ট রোডম্যাপ (Signature-স্টাইল ফেজ)

> এই ফাইলটা Claude Code-এর জন্য লেখা। প্রতিটা স্প্রিন্ট আলাদাভাবে ইমপ্লিমেন্ট হবে — এক স্প্রিন্ট শেষ ও ভেরিফাই না হলে পরেরটা শুরু নয়।
> ব্যাকগ্রাউন্ড: ফিচার এনালাইসিস `docs/barber-shop-feature-analysis.md`, মাস্টার প্ল্যান `docs/queueflow-master-plan.md`, প্রোডাক্ট স্পেক `PROJECT-SPEC.md`।

## কনফার্মড সিদ্ধান্ত (সব স্প্রিন্টে প্রযোজ্য)

1. **লেআউট রিইউজ, স্টাইল সোয়াপ:** Palaa-র বিদ্যমান লেআউট স্ট্রাকচার ও কম্পোনেন্ট যতটা সম্ভব অক্ষত থাকবে; শুধু **কালার টোকেন + কম্পোনেন্ট স্টাইল** Signature Salon (লাল/কোরাল, সাদা কার্ড, পিল বাটন) থিমে বদলাবে। নতুন স্ক্রিন বানালে Signature-এর UI প্যাটার্ন (বটম-শিট, চিপ, ট্যাব বার) ব্যবহার হবে।
2. **প্রোভাইডার UI:** ডার্ক সাইডবার লেআউট থাকবে, শুধু accent/কম্পোনেন্ট স্টাইল Signature-রেডে সোয়াপ।
3. **নোটিফিকেশন আগে, পেমেন্ট পরে:** নোটিফিকেশন Sprint 2। রিয়েল পেমেন্ট গেটওয়ে এখন **ইন্টিগ্রেট হবে না** — বিদ্যমান mock-gateway ইন্টারফেস আর Payment Methods UI (bKash/Nagad/Rocket/Card অপশনসহ) রেখে দেওয়া হবে, যেন পরে শুধু গেটওয়ে সোয়াপ করলেই চলে।
4. **ভাষা:** সব UI টেক্সট বাংলা। ইংরেজি টগল Sprint 10-এ।
5. **সব স্প্রিন্টে বাধ্যতামূলক:** মোবাইল-ফার্স্ট রেসপনসিভ (ছোট ফোন → ট্যাবলেট → ডেস্কটপ), বিদ্যমান ফিচার ভাঙা যাবে না, `npm run build` ও lint সবুজ হয়ে তবেই কমিট, প্রতি স্প্রিন্ট শেষে অর্থবহ কমিট মেসেজ।
6. **স্ট্যাক অপরিবর্তিত:** Next.js App Router + Supabase (Auth/Postgres/Realtime/Storage)। নতুন টেবিল লাগলে `supabase/migrations/`-এ SQL মাইগ্রেশন ফাইল।

## Sprint 1 — Signature-রেড রি-স্কিন

**লক্ষ্য:** পুরো অ্যাপের ভিজ্যুয়াল টোন Palaa-warm থেকে Signature Salon-এ (লাল/কোরাল #E85B5B ঘরানা) — লেআউট না ভেঙে।

- [ ] `globals.css`-এর থিম টোকেন সোয়াপ: `--accent` → কোরাল-রেড স্কেল (hover/pressed শেডসহ), `--paper` → হালকা অফ-হোয়াইট, `--card` → সাদা, স্ট্যাটাস রংগুলো (`--live`, `--good` ইত্যাদি) নতুন প্যালেটের সাথে সামঞ্জস্যপূর্ণ করা; কনট্রাস্ট AA রাখা
- [ ] Button/Badge/Pill: ফুল-রাউন্ডেড (পিল) স্টাইল, প্রাইমারি = লাল ফিল + সাদা টেক্সট, সেকেন্ডারি = লাল আউটলাইন
- [ ] কার্ড: সাদা সারফেস, নরম শ্যাডো, বড় রেডিয়াস — Signature-এর মতো
- [ ] কাস্টমার বটম নেভ ও প্রোভাইডার সাইডবারের active state লাল accent-এ
- [ ] প্রোভাইডার ডার্ক সাইডবার থাকবে — শুধু accent বদল
- [ ] সব বিদ্যমান স্ক্রিন ঘুরে দেখে রঙ-সংক্রান্ত রিগ্রেশন ঠিক করা (হার্ডকোডেড পুরনো রং খুঁজে টোকেনে আনা)

**Acceptance:** কোনো স্ক্রিনে পুরনো Palaa accent দেখা যাবে না; লেআউট/স্পেসিং অপরিবর্তিত; মোবাইল+ডেস্কটপ দুটোতেই চেক করা।

## Sprint 2 — নোটিফিকেশন সিস্টেম

**লক্ষ্য:** in-app Notification Center + রিয়েলটাইম আপডেট + দোকানদারের ব্রডকাস্ট। (Web Push/service worker এই স্প্রিন্টে optional — আগে in-app শেষ হবে।)

- [ ] মাইগ্রেশন: `notifications` টেবিল (user_id, type: SERIAL_CONFIRMED/QUEUE_UPDATE/YOUR_TURN/CANCELLED/PROMO/REMINDER, title, body, data jsonb, read_at, created_at) + RLS
- [ ] সিরিয়াল লাইফসাইকেল ইভেন্টে নোটিফিকেশন তৈরি (DB trigger বা সার্ভার লজিক): বুকিং কনফার্ম ("তোমার সিরিয়াল #N"), আগে ২ জন বাকি, "এখন তোমার পালা", ক্যানসেল
- [ ] কাস্টমার UI: হেডারে বেল আইকন + unread ব্যাজ; Notification Center পেজ — ডেট-গ্রুপড লিস্ট (আজ/গতকাল/তারিখ), ট্যাপে read মার্ক, সব read মার্ক বাটন; Supabase Realtime-এ লাইভ আসবে
- [ ] প্রোভাইডার ব্রডকাস্ট: ড্যাশবোর্ড থেকে "নোটিফিকেশন পাঠান" — টার্গেট (সব কাস্টমার যারা আগে এসেছে / regulars), টাইটেল+মেসেজ; স্প্যাম ঠেকাতে দিনে সীমিত সংখ্যা
- [ ] regulars রিমাইন্ডারকে এই সিস্টেমে যুক্ত করা (রিমাইন্ডার পাঠালে কাস্টমারের Notification Center-এ পৌঁছাবে)

**Acceptance:** দুই ব্রাউজারে (কাস্টমার+প্রোভাইডার) খুলে বুকিং দিলে রিফ্রেশ ছাড়া নোটিফিকেশন আসে; ব্রডকাস্ট কাস্টমারে পৌঁছায়।

## Sprint 3 — Auth + অনবোর্ডিং সম্পূর্ণ

- [ ] Forgot Password: লগইনে "পাসওয়ার্ড ভুলে গেছেন?" → Supabase reset ইমেইল → নতুন পাসওয়ার্ড সেট পেজ
- [ ] Password Manager: অ্যাকাউন্ট সেটিংসে পাসওয়ার্ড বদল (বর্তমান/নতুন/কনফার্ম)
- [ ] সাইনআপের পর Complete Profile ধাপ: ছবি, ফোন, জেন্ডার (skip-able)
- [ ] কাস্টমার লোকেশন: প্রথমবার explore-এ location permission প্রম্পট স্ক্রিন (Signature-স্টাইল illustration) + "ম্যানুয়ালি দিন" অপশন; অনুমতি পেলে **দূরত্ব-ভিত্তিক সর্ট + প্রতি শপ কার্ডে দূরত্ব** দেখানো
- [ ] Logout কনফার্মেশন বটম-শিট ("সত্যিই লগ আউট করবেন?")

## Sprint 4 — শপ ডিটেইল ২.০

- [ ] শপ ডিটেইল পেজ ট্যাবড লেআউটে: **সার্ভিস / স্টাফ / গ্যালারি / রিভিউ / বিস্তারিত** (হরাইজন্টাল স্ক্রল ট্যাব বার); বুকিং ফ্লো (সার্ভিস মাল্টি-সিলেক্ট + স্টিকি বটম CTA) অক্ষত থাকবে
- [ ] হিরো কভার ফটো + ফ্লোটিং রেটিং ব্যাজ (★ গড় + রিভিউ সংখ্যা)
- [ ] Quick Actions রো: কল (tel:), মেসেজ (বিদ্যমান চ্যাটে), ডিরেকশন (Google Maps/OSM লিংক lat,lng দিয়ে), শেয়ার (Web Share API, fallback: লিংক কপি)
- [ ] স্টাফ ট্যাব: চেয়ার/স্টাফ কার্ড (ছবি, নাম, কোন সার্ভিস পারে)
- [ ] গ্যালারি ট্যাব: ফটো গ্রিড; দোকানদার সেটিংসে গ্যালারি আপলোড (Supabase Storage, একাধিক ছবি)
- [ ] বিস্তারিত ট্যাব: About টেক্সট + **সাপ্তাহিক Working Hours টেবিল** — মাইগ্রেশন: shops-এ `about` + `weekly_hours` jsonb; দোকানদার সেটিংসে এডিট UI; open/close টগলের পাশে দিনভিত্তিক সময় দেখানো
- [ ] বুকিংয়ে **পছন্দের স্টাফ (optional)**: auto-assign ডিফল্ট, চাইলে নির্দিষ্ট চেয়ার/স্টাফ বাছা যাবে (সেই চেয়ারের ব্যাকলগ অনুযায়ী ETA)

## Sprint 5 — বুকিং হিস্ট্রি + E-Receipt + Favorites

- [ ] কাস্টমার "আমার বুকিং" পেজ ৩-ট্যাব: **চলমান / সম্পন্ন / বাতিল** (Signature-স্টাইল কার্ড: তারিখ-সময়, দোকান, ঠিকানা, সিরিয়াল কোড)
- [ ] বাতিল ট্যাবে **আবার বুক করুন** (Re-Book): same shop+services দিয়ে নতুন সিরিয়াল ফ্লো শুরু
- [ ] সম্পন্ন বুকিংয়ে **E-Receipt**: QR কোড (serial code এনকোডেড), দোকান+সার্ভিস+দাম আইটেমাইজড, টোটাল, ডাউনলোড (client-side image/PDF)
- [ ] কাস্টমার Transactions পেজ: ডেট-গ্রুপড খরচের লিস্ট (বিদ্যমান spending ডেটা রিইউজ)
- [ ] Favorites: শপ কার্ড ও ডিটেইলে ♥ টগল; মাইগ্রেশন `favorites` টেবিল; প্রোফাইলে "প্রিয় দোকান" পেজ (ক্যাটাগরি ফিল্টার চিপ)

## Sprint 6 — হোম রিচনেস + অফার + ফিল্টার/সার্চ

- [ ] মাইগ্রেশন: `offers` টেবিল (shop_id, title, description, discount_pct, valid_until, active)
- [ ] দোকানদার অফার ম্যানেজমেন্ট পেজ: অফার তৈরি/বন্ধ; তৈরি হলে regulars-দের নোটিফিকেশন (Sprint 2-এর ব্রডকাস্ট রিইউজ)
- [ ] কাস্টমার হোম/explore-এর উপরে **অফার ব্যানার ক্যারোসেল** (Signature #SpecialForYou স্টাইল: ডার্ক কার্ড, ডিসকাউন্ট বড় করে, দোকানের নাম, "দেখুন" CTA → শপ ডিটেইল)
- [ ] সার্ভিস-ক্যাটাগরি শর্টকাট রো (গোল আইকন: চুল কাটা, শেভ, ফেসিয়াল...) → ট্যাপে সেই সার্ভিস আছে এমন দোকান ফিল্টার
- [ ] টপ-রেটেড সেকশন (গড় রেটিং সর্ট)
- [ ] সার্চ বার: দোকান/সার্ভিস নামে খোঁজা
- [ ] ফিল্টার বটম-শিট: ধরন (সেলুন/পার্লার), রেটিং রেঞ্জ, দূরত্ব স্লাইডার, খোলা-শুধু টগল; Reset + Apply

## Sprint 7 — চ্যাট ২.০ + রিভিউ ২.০

- [ ] Chats লিস্ট পেজ (কাস্টমার ও প্রোভাইডার দুই সাইডে): সব কনভার্সেশন — অ্যাভাটার, নাম, শেষ মেসেজ, সময়, unread ডট
- [ ] চ্যাট থ্রেডে ছবি পাঠানো (Supabase Storage) + online/last-seen ইন্ডিকেটর (Supabase Presence)
- [ ] রিভিউয়ে ছবি অ্যাটাচ (একাধিক), শপ রিভিউ ট্যাবে ফিল্টার চিপ: সর্বশেষ / ছবিসহ; verified ব্যাজ (সার্ভিস নেওয়া কাস্টমার — ডেটা এমনিতেই আছে)
- [ ] রিভিউয়ে স্টাফ ট্যাগ (কোন চেয়ার/স্টাফ সার্ভিস দিয়েছিল — serial থেকে অটো) → স্টাফ কার্ডে per-staff গড় রেটিং

## Sprint 8 — বাকি খাতা + পেমেন্ট অপশন (গেটওয়ে ছাড়া)

- [ ] মাইগ্রেশন: serial-এ payment স্ট্যাটাস বাড়ানো (PAID/DUE/ADVANCE) + `due_payments` ট্র্যাকিং
- [ ] প্রোভাইডার **বাকির খাতা** পেজ: কার কাছে কত বাকি (কাস্টমার-প্রতি ব্যালেন্স), "Done" মার্ক করার সময় "বাকি রাখলো" অপশন, পরে "আদায় হয়েছে" মার্ক → ইনকামে তখন যোগ হবে
- [ ] বাকি থাকলে কাস্টমারকে নোটিফিকেশন/রিমাইন্ডার পাঠানোর বাটন
- [ ] কাস্টমার Payment Methods স্ক্রিন: Cash (ডিফল্ট) / bKash / Nagad / Rocket / কার্ড — **UI + সিলেকশন শুধু; অনলাইন অপশনগুলোতে "শীঘ্রই আসছে" স্টেট**; বিদ্যমান mock-gateway ইন্টারফেস অক্ষত (পরে রিয়েল গেটওয়ে সোয়াপ)

## Sprint 9 — সাপোর্ট পেজ + পলিশ

- [ ] Help Center: FAQ অ্যাকর্ডিয়ন (সার্চ + ক্যাটাগরি চিপ) + যোগাযোগ ট্যাব (ফোন/WhatsApp/সোশ্যাল লিংক)
- [ ] Privacy Policy + Terms + Cancellation Policy স্ট্যাটিক পেজ
- [ ] Delete Account ফ্লো (কনফার্মেশন + Supabase ডেটা হ্যান্ডলিং)
