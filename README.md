# QueueFlow (পালা) — লাইভ সিরিয়াল ম্যানেজমেন্ট

সেলুন/পার্লারের জন্য লাইভ কিউ সিস্টেম — কাস্টমার আশেপাশের দোকান দেখে অনলাইনে সিরিয়াল বুক করে, রিয়েলটাইমে নিজের পজিশন ও ETA ট্র্যাক করে; দোকানদার একটা লাইভ কিউ বোর্ডে সিরিয়াল ম্যানেজ করে এবং ইনকাম/অ্যানালিটিক্স দেখে।

## কেন

দোকানে গিয়ে ৩০ মিনিট–২ ঘণ্টা বসে থাকা, সিরিয়াল কখন আসবে না জানা, দোকানদারের ম্যানুয়াল খাতা — এসবের সমাধান: লাইভ কিউ, আনুমানিক অপেক্ষার সময়, অনলাইন সিরিয়াল, আর দোকানদারের জন্য পূর্ণ ম্যানেজমেন্ট ড্যাশবোর্ড।

## মূল ফিচার

**কাস্টমার:** আশেপাশের খোলা দোকান (লিস্ট + ম্যাপ, লাইভ কিউ কাউন্ট) → সার্ভিস বেছে সিরিয়াল বুক → লাইভ ট্র্যাকিং (পজিশন, ETA কাউন্টডাউন) → রিভিউ, চ্যাট, নোটিফিকেশন

**দোকানদার:** লাইভ কিউ বোর্ড (চেয়ার/স্টাফ-ভিত্তিক, Start/Done, walk-in) → সার্ভিস ও রেট ম্যানেজমেন্ট → ইনকাম ট্র্যাকিং → বিজনেস অ্যানালিটিক্স (peak hours/days) → নিয়মিত কাস্টমার + রিমাইন্ডার → কাস্টমার Trust Score

দুই ধরনের ব্যবসা এক প্ল্যাটফর্মে: **Salon** ও **Parlour** (`business_type` দিয়ে আলাদা)।

## স্ট্যাক

Next.js (App Router) + React + Tailwind · Supabase (Auth / Postgres / Realtime / Storage) · Leaflet + OpenStreetMap

কিউ/ETA লজিক সার্ভার-সাইডে (Postgres ফাংশন), সব আপডেট Supabase Realtime-এ লাইভ।

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Supabase কনফিগ `.env.local`-এ।
